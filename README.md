# 💸 Nikel - Controle Financeiro Simples

Um aplicativo web para gerenciamento de finanças pessoais que permite aos usuários registrar entradas e saídas, visualizar o saldo total e manter o controle de todos os lançamentos em um único lugar.

Este projeto foi desenvolvido como um exercício prático para aplicação de **HTML**, **CSS**, **Bootstrap** e **JavaScript**, com foco em persistência de dados utilizando o **Local Storage**.

---

## ✨ Funcionalidades

* **Login e Cadastro:** Sistema básico de autenticação com persistência de sessão.
* **Controle de Lançamentos:** Adicione e visualize transações de **Entrada** e **Saída**.
* **Cálculo de Saldo:** Exibição do saldo total em tempo real na página inicial (`home`).
* **Histórico de Transações:** Lista completa de todos os lançamentos registrados na página de transações (`transactions`).
* **Persistência de Dados:** Todos os dados do usuário (conta e transações) são salvos localmente no **Local Storage** do navegador.
* **Design Responsivo:** Utilização do **Bootstrap 5** para garantir uma interface agradável e adaptável a diferentes dispositivos.

---

## 🛠️ Tecnologias Utilizadas

O projeto é construído com base nas tecnologias fundamentais da web:

| Tecnologia | Descrição |
| :--- | :--- |
| **HTML5** | Estruturação da aplicação (páginas de login, home e transações). |
| **CSS3** | Estilização personalizada, incluindo gradientes e cores definidas (`#4e0070` e `#4c79d3`). |
| **JavaScript (ES6+)** | Lógica de autenticação, manipulação do DOM, cálculo de saldos e persistência de dados. |
| **Bootstrap 5** | Framework de CSS e JS para o design responsivo, modais e componentes de layout. |
| **Bootstrap Icons** | Iconografia utilizada para navegação e indicadores de transação. |
